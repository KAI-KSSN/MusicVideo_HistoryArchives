# Canon evidence records

Evidence records preserve field-level sources before a Supabase migration is
prepared. A record is not a publication instruction. `NULL` is retained when
an authoritative source has not been found, and an award program remains
`not_checked` until its official archive has actually been reviewed.

Title collisions are resolved by artist, year, client, and work type. Awards
for a film, advertisement, song recording, artist, or later reuse of the same
title are not attached to the music video.
