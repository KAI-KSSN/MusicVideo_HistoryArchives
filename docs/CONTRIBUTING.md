# Contributing

## Before Adding a Work

Confirm that the work fits the editorial policy.

## Required Minimum Information

- Title
- Artist
- Release year
- Official or reliable reference URL
- Reason for inclusion
- Research status

## Preferred Information

- Director
- Production company
- VFX production
- Awards
- Techniques
- Historical context
- Sources

## Rules

- Do not guess credits.
- Do not publish unverified information as fact.
- Do not duplicate entities with alternate spellings.
- Add sources for important factual claims.
- Keep schema changes in Supabase migrations.
